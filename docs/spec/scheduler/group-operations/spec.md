# ジョブグループの運用と入出力

## 目的

ルート配下のグループでジョブネットを整理し、業務単位で予定実行を停止・再開し、定義を持ち運ぶ。

## 仕様

- 実行ボタンは予定実行の再開。配下ネットの即時一括起動は行わない。
- 全体、祖先、自身のいずれかの停止が新規開始を抑止する。実行中プロセスの結果回収は続ける。開始済みネットの未開始ジョブは再開まで待つ。
- 再開時刻より前の未開始ルート予定は見送る。開始済み世代は継続する。停止状態・再開境界はStorageへ保存する。
- 新規配置・削除後の再登録では、反映時刻より前の自動予定を起動しない。改名による当日の過去予定の再実行を防ぐ。固定グループIDから旧世代の予定枠を引き継ぎ、複数回の改名でも個別保留・開始済みの未来世代を二重生成しない。自動登録の解除も維持する。
- 改名をまたいだ別の予定枠でも、同一グループID内の同名ルートについて `mp=n` の開始済み世代と結果不明世代を起動抑止に含める。結果不明は `mp=y` でも抑止する。
- 不正な改名元・重複した改名対応の運用反映は永続的に拒否し、後続操作を妨げない。
- グループ操作の通信失敗・再読込後も保存した同一操作IDで再照会・再送できる。受付不明を成功や取消とみなさない。
- グループIDはパスと分離する。改名でIDを維持し、削除後の新規作成は別IDにする。実行世代は作成時の所属に固定する。
- 定義反映で新規グループは停止状態にする。既存グループの置換は対象の停止状態を維持する。旧データ移行は対象外。旧形式の運用Storageは自動変換せず、認識できない形式として停止する。
- エクスポートは選択グループ以下の定義と配置情報を含むZIP。運用状態や内部IDは含まない。選択外への参照は保持し、祖先継承を診断情報として記録する。依存先は同梱しない。
- インポートは新規追加または選択グループ置換。検証した候補を下書きに取り込み、運用反映は別の確認操作とする。対象外の原文・文字コード・BOMを保持する。
- 管理APIを使用し、JP1 HTTP独自拡張は追加しない。旧版との混在は不可。

## 受入条件

| 条件・操作 | 期待する結果 |
| --- | --- |
| 親停止中に子だけ再開 | 子は親からの停止を表示し、起動しない |
| 一方のグループを停止 | 兄弟は通常運用を継続 |
| 実行中に停止・再開 | 結果回収を続け、未開始子だけ待機 |
| 長期停止後の再開 | 件数・日数両方式で過去の未開始ルートを再実行しない |
| 操作再送・中断・リース交代 | 同一計画を復旧し重複起動や更新消失を起こさない |
| 改名・反映・再起動 | 停止状態と開始済み世代の所属を維持 |
| グループZIPの追加・置換 | 下書きだけ変更し、undoと再取込で内容を確認できる |
| 外部参照・危険なZIP | 具体的な理由を返し既存の編集を保持 |
| 旧下書き・複数タブ | 読込互換と保存競合保護を維持 |

## 管理API

- `GET /api/jobrunner/ui/groups` は固定ID、現在の完全名、運用版、制御版、自身の停止、実効停止元、旧所属かを返す。
- `POST /api/jobrunner/operations` の `Kind=PauseGroup/ResumeGroup` は `Target` に上記ID、`ExpectedControlRevision` と `ExpectedDefinitionRevision` に確認済みの版を指定する。既存の `Id` 冪等性キーと非同期操作照会を使用する。受付と適用完了は区別する。古い版は操作結果 `Rejected` として拒否する。
- `POST /api/jobrunner/ui/definition-editor/groups/export` は `Draft` と現在の完全名 `Path` からZIPを返す。
- `POST /api/jobrunner/ui/definition-editor/groups/import` は `Draft`、`ZipBase64` と置換対象の `Path`、または新規追加先の `ParentPath` / `Name`（この場合 `Path` は空文字）を受け取る。返すのは `EditorDocument` の候補であり、保存・運用反映はしない。
- 反映プレビューにはグループの新規停止と改名・配置変更の影響を含め、停止制御行のETagも影響ハッシュで照合する。
