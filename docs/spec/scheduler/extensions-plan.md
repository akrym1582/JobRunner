# 確定登録・運用API・スケジュール拡張

合意範囲は確定登録の期間/日時、運用HTTP、ネスト、相対日/月区分/基準日/起算/時刻間隔、補充用定義更新、条件分岐/異常時後続、通常ジョブの再実行方式。計画登録、待ち合わせ、イベント、別形式アダプター、OSユーザー切替は対象外。

実装順は定義版固定→登録方式→ネストと計算→運用制御→HTTPと統合検証。新しいPRひとつで管理し、各段階のコミットと受入試験を分ける。完了していない機能を対応済みとしない。

## 一次資料

JP1 V12 3021-3-D28-20。7.1.6の固定登録は期間と件数の併用可、日時と期間/件数の併用不可。日時省略時の過去時刻動作などは独自復旧規則との違いを明示する。7.4.10のルート再実行はTOP/ABNORMAL_JOB/ABNORMAL_NEXT/ABNORMAL_JOBNET/WARNING、下位はFROM/ONLY/NEXT。

## 保存と復旧

世代ごとの定義版を不変に固定する。登録の補充用版だけを期待版つき操作で更新する。旧データは採用版へ固定し、最新の補充版へ読み替えない。開始済み・生成済みの世代を新版へ変換しない。旧版の操作要求ハッシュは維持する。

## 受入

既存78ケース、旧データ復旧、同一ID再送、分割更新の中断/応答喪失、長期停止、部分世代、Unknown非再実行、複数インスタンス、1000プロセス、HTTP/Storage/実プロセスを含む全試験。Linux/Azurite必須、実JP1比較とWindows実機は別途。
