# グループ・ルート移動と外部依存ZIP

グループと通常ルートは別グループ・別Unitファイルへ移動できる。省略属性は移動先から継承し、変更パス・参照・継承差を確認後、一つのundo操作として下書きへ適用する。グループとルートの同一性は運用反映でも維持する。開始済み世代は旧定義・旧所属に固定し、多重起動、Unknown、消化済み予定と解除状態を保護する。

ZIPは選択範囲だけを含め、明示的な外部jcを保持する。外部定義は同梱しない。暗黙継承は取込先に従い、元の継承情報は診断だけに用いる。依存不足でも下書きへ取込・保存・再出力できるが、運用反映と予定計算は完全検証を必須とする。

対象外: ルートと子ネットの相互変換、階層の役割変換、仮想グループの直接移動。衝突・循環・表現不能な文字・空になる元ファイルは理由付きで拒否する。未編集バイト、文字コード、BOM、未対応属性、複数タブ競合と古い応答からの保護を維持する。旧運用形式の移行は行わず新規Storageへ導入する。

検証: 同一/別ファイル、独立ファイル子孫、jc追従、継承差、ZIP版1/2、未解決依存保存/解決後反映、undo/redo/再読込/競合。運用はRunning/Unknown、件数/日数、保護枠、解除、部分保存復旧を試験する。検証結果は[検証記録](verification.md)を参照する。

グループ・ルートの移動候補APIは `/api/jobrunner/ui/definition-editor/move`。対象下書き・完全名・移動先・ファイル識別情報（名前、配置先、文字コード）を受け、候補文書と診断を返す。旧要求のSourceIndex指定も受け付ける。版9下書きの任意RootOrigins、EditorDocumentの任意Diagnosticsを追加し、旧下書きの欠落項目は削除と解釈しない。

確認表示では継承チェーンに加え、サービスの時間帯における今日から31日間・先頭50ルートの実効カレンダー差を既存エンジンで比較する。2秒を超えた比較は診断を示して打ち切る（原文読込と意味検証は別）。全期間・全ルールの予定は既存の下書き試算で確認する。移動先ファイルの並び順が変わっても識別情報で照合する。移動ブロックの前後に改行を置き、末尾コメントを属性と同じ行へ結合しない。

APIで追加した個別の確定登録が有効なルートは、下書き移動は可能だが運用反映を拒否する。期間・除外・間隔・件数などの登録条件を自動登録へ黙って置換しないため、利用者が登録条件を確認して旧登録を解除し、移動後に再登録する。自動確定登録の解除状態と保護枠は固定IDから引き継ぐ。

運用定義・ローカル定義の読込・移動候補に任意OriginCatalogHashを固定する。所属カタログが変わった後に古い下書きを再反映し、古い元パスから新しい固定IDを黙って作らないよう、反映プレビューで所属版を比較する。移動や新規追加を運用反映した後は最新の運用定義を開き直して次の編集を始める。所属変更のないコマンド等の編集ではこの再読込を要求しない。旧下書きの省略項目は受理し、新しい移動候補を生成する際に現在の所属版を固定する。

## グループへのテキスト取り込み

グループのインポートは、従来のJobRunner出力ZIPに加え、JP1 Unit定義のテキストファイル1つを受け付ける。拡張子は制限せず、`.zip` は従来のZIPとして扱う。文字コードはUTF-8（既定）、UTF-16LE/BE、Shift_JISから明示する。原文は各2MiBまでで、BOM不一致・不正な構文・空入力を拒否する。構文と属性の対応範囲は既存のUnitパーサーに従う。これはJobRunner独自の編集入力であり、JP1 HTTP契約は変更しない。

テキストの最上位が単一グループならそのグループを追加・置換する。それ以外のジョブネット等の定義は、指定したグループの配下へまとめる。単一グループ内の明示jcは移動先へ追従し、外部参照は保持する。原文の文字コード・BOM・未変更部分のバイトを保持する。取り込みは一つのundo可能な下書き操作であり、運用への反映は既存のプレビューに従う。

受入条件:
- テキストを選び文字コードを指定すると、新規追加と既存グループ置換の両方ができる。対象外グループは維持する。
- グループを含まないジョブネット定義も追加でき、保存・再読込・undoが従来どおり働く。
- ZIPとテキストの同時指定、不正文字コード・BOM・構文・サイズ超過、同名衝突を拒否し、現在の下書きを維持する。
- 既存のZIP版1/2、外部依存の診断、原文保持を維持する。


## 移動元の識別と依存診断

- 移動元は現在のカタログの固定ルートIDから特定し、移動先の過去の自動登録行を制御状態の根拠にしない。移動元の解除・件数などの条件を移動先へ複製する。同名の旧ネットによる抑止枠・件数カーソルを混ぜないよう、移動後の登録にSlotIdentityを固定する。旧世代の解除状態は必要な場合だけRegistrationDisabledSnapshotへ保存し、別ネットによる登録行の再利用で変化させない。
- 新しい移動画面は従来のnetworkChanges.parentPathを適用した完全名を使う。連続移動・保存・再読込でも現在のパスを送る。
- 外部依存診断は同じ参照先をまとめ、参照元の件数と最大3例を表示する。ZIPに載せる診断は128KiB以内へ要約し、省略件数を明記する。参照そのものは原文にすべて保持し、取込時に再検証する。非圧縮manifest全体が256KiBを超える場合は出力時に拒否し、再取込不能なZIPを返さない。

固定ルートIDが記録されている世代は、そのIDが反映先に残る場合だけ保護枠を移す。IDが消えた世代を、親グループIDの一致から別ネットへ補完しない。固定IDそのものが記録されていない場合だけ、従来のグループ単位のパス補完を使用する。

## ジョブ・子ネットの選択移動

同じ親ネット直下の編集可能なジョブ・子ネットを単体または複数選択し、別の通常/リカバリーネットへ移動できる。子孫と内部の通常/条件接続を保持し、選択範囲外との接続は方向・種別を列挙して確認後に切断する。移動先に既存ユニットへの接続を自動追加しない。判定先行やリカバリー接続等が不正になる候補は、関連ユニットの選択を案内して全体拒否する。

`POST /api/jobrunner/ui/definition-editor/move-selection` は現在の下書き、同じ親の選択ID一覧、移動先ネットIDを受け、EditorDocumentと診断を返す。IDは現在の編集を反映したパスへ解決する。重複・異なる親・同じ親への移動・自己/子孫・同名衝突・完全名上限を拒否し、種別変更やルートとの相互変換は行わない。移動先ファイルは親ネットの原文所属から決める。

明示属性・座標・外部カレンダー参照を保持し、省略属性と上位ルールは移動先で評価する。継承元・参照・上位ルールの変更影響と座標重複を診断する。移動先が不正な上位ルールになる場合は拒否する。確認取消では下書きを変えず、適用は一つのundoで戻せる。原文バイト、未知属性、BOM、独立ファイル配置は既存移動と同じく保持し、文字コード変換は移動部分だけに限定する。運用データは候補生成・保存で変更せず、運用反映後も開始済み世代は固定定義のまま、ルートIDと登録状態を保持する。

同じ固定IDが元のパスへ戻る場合も、新しい登録のSlotIdentityに対応する保護枠を記録する。パスが同じことだけで旧キーの枠が使えると判断しない。消えた旧固定IDの保護枠を同名の別ネットへコピーしない条件は維持する。
