# グループ・ルート移動と外部依存ZIP

合意: グループと通常ルートを別グループ・別Unitファイルへ移動する。省略属性は移動先から継承し、変更パス・参照・継承差を確認後、一つのundo操作として下書きへ適用する。グループとルートの同一性は運用反映でも維持する。開始済み世代は旧定義・旧所属に固定し、多重起動、Unknown、消化済み予定と解除状態を保護する。

ZIPは選択範囲だけを含め、明示的な外部jcを保持する。外部定義は同梱しない。暗黙継承は取込先に従い、元の継承情報は診断だけに用いる。依存不足でも下書きへ取込・保存・再出力できるが、運用反映と予定計算は完全検証を必須とする。

対象外: ジョブ・子ネットの別親移動、階層の役割変換、仮想グループの直接移動。衝突・循環・表現不能な文字・空になる元ファイルは理由付きで拒否する。未編集バイト、文字コード、BOM、未対応属性、複数タブ競合と古い応答からの保護を維持する。旧運用形式の移行は行わず新規Storageへ導入する。

検証: 同一/別ファイル、独立ファイル子孫、jc追従、継承差、ZIP版1/2、未解決依存保存/解決後反映、undo/redo/再読込/競合。運用はRunning/Unknown、件数/日数、保護枠、解除、部分保存復旧を試験する。全体回帰と最新CIを確認しドラフトPRで提供する。

移動候補APIは `/api/jobrunner/ui/definition-editor/move`。対象下書き・完全名・移動先・ファイル識別情報（名前、配置先、文字コード）を受け、候補文書と診断を返す。旧要求のSourceIndex指定も受け付ける。版9下書きの任意RootOrigins、EditorDocumentの任意Diagnosticsを追加し、旧下書きの欠落項目は削除と解釈しない。

確認表示では継承チェーンに加え、サービスの時間帯における今日から31日間・先頭50ルートの実効カレンダー差を既存エンジンで比較する。2秒を超えた比較は診断を示して打ち切る（原文読込と意味検証は別）。全期間・全ルールの予定は既存の下書き試算で確認する。移動先ファイルの並び順が変わっても識別情報で照合する。移動ブロックの前後に改行を置き、末尾コメントを属性と同じ行へ結合しない。

APIで追加した個別の確定登録が有効なルートは、下書き移動は可能だが運用反映を拒否する。期間・除外・間隔・件数などの登録条件を自動登録へ黙って置換しないため、利用者が登録条件を確認して旧登録を解除し、移動後に再登録する。自動確定登録の解除状態と保護枠は固定IDから引き継ぐ。

運用定義・ローカル定義の読込・移動候補に任意OriginCatalogHashを固定する。所属カタログが変わった後に古い下書きを再反映し、古い元パスから新しい固定IDを黙って作らないよう、反映プレビューで所属版を比較する。移動や新規追加を運用反映した後は最新の運用定義を開き直して次の編集を始める。所属変更のないコマンド等の編集ではこの再読込を要求しない。旧下書きの省略項目は受理し、新しい移動候補を生成する際に現在の所属版を固定する。
